# 3D Islands Portfolio

**A creative 3D web experience built to showcase my development work.**  
[Live Site](https://stefansecrieru.com) | [GitHub Repo](https://github.com/Stefan3002/3D-Islands-Portfolio)

## Overview

The 3D Islands Portfolio is a visually rich, interactive website that presents my professional profile using a blend of modern web development technologies and 3D rendering. It merges aesthetics with performance to deliver an immersive browsing experience that reflects my passion for both frontend development and design.

---

## ✨ Features

- 🏝️ 3D island navigation for different content sections
- 🌀 Smooth transitions and animations using Three.js
- 📱 Fully responsive design + it looks better on mobile actually :)
- ⚡ Optimized for performance

---

## 🛠 Technologies Used

- React JS
- Three.js
- React Three Fiber
- Framer Motion

---

## 🧑‍💼 Purpose

- Serve as a personal portfolio for showcasing web development, AI, and educational projects
- Demonstrate creative and technical skills in a real-world web application
- Provide a unique, memorable UX for visitors, employers, and collaborators

---

## 🚀 Getting Started

### Requirements

- Node.js (v14+ recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/Stefan3002/3D-Islands-Portfolio.git
cd 3D-Islands-Portfolio
npm install
npm run dev
```
